# Design implementation

The supplied Léxico Vivo design system and screenshots remain the visual reference. The frontend-design skill informed the implementation and visual review.

- Palette: parchment `#fcf9f4`, white `#fffefd`, linen `#f3eee7`, espresso `#3b271e`, muted umber `#746759`, and caramel `#97501f`. The darker metadata/accent shades improve contrast while retaining the source palette.
- Type: local Merriweather for headwords, editorial headings and quotations; local Plus Jakarta Sans for definitions, navigation and controls.
- Layout: a left-aligned literary landing page with a large typographic opening; dictionary entries use a broad reading column with a narrower discovery sidebar. On mobile, the reading column comes first and the sidebar follows.
- Identity: an open-book and speech-bubble mark, quiet paper surfaces, restrained caramel rules, source-backed definitions, and real regional counts. The typographic watermark carries the landing page's visual emphasis.
- Review: full-page desktop and mobile screenshots, viewport overflow checks, keyboard workflows, and automated WCAG AA checks. The original prototype's fabricated activity counts and unsupported historical claims are omitted.
